## Basic usage

Set the `texture` property to an image URL. The image is applied as a CSS background on each face of the voxel.

```ts
const voxels = [
  { x: 1, y: 1, z: 0, texture: "/grass.png" },
  { x: 2, y: 1, z: 0, texture: "/grass.png" },
  { x: 1, y: 2, z: 0, texture: "/grass.png" },
];
```

## Combining texture and color

You can set both `texture` and `color` on the same voxel. The color acts as a **fallback** if the texture fails to load, and as a **tint** that blends with the texture.

```ts
const voxels = [
  { x: 0, y: 0, z: 0, color: "#8B4513", texture: "/wood.png" },
  { x: 1, y: 0, z: 0, color: "#228B22", texture: "/grass.png" },
];
```

This is useful for giving textured voxels a base color so they don't flash white while images load.

## Texture sources

The `texture` value is any valid CSS image URL. You can use:

- **Relative paths** — files in your project's public directory (e.g., `/grass.png`)
- **Absolute URLs** — hosted images (e.g., `https://example.com/texture.png`)
- **Data URIs** — inline base64-encoded images

```ts
// Relative path
{ x: 0, y: 0, z: 0, texture: "/textures/brick.png" }

// Absolute URL
{ x: 1, y: 0, z: 0, texture: "https://example.com/stone.png" }
```

## Tips

- Use **small, tileable images** (e.g., 16×16 or 32×32 pixels) for the best look at voxel scale.
- Textures are rendered via CSS `background-image`, so they benefit from browser caching automatically.
- For scenes with many textured voxels, reuse the same image URL — the browser only fetches it once.
